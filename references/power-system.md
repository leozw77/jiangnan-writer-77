# Power System Reference v1

## Core Rules

- 77 is an independent variable in the Dragon world and does not replace the original protagonists.
- Power progression must preserve uncertainty and cost.

## Soul Rings / Levels

- Nine soul rings are not equal to level 99.
- When Lu Mingze borrows 77's body and displays nine rings, this represents approximately level 90 combat power.
- Level 99 represents the second life's divine-level peak state of 77.
- The second life's divine status has been damaged and cannot be freely restored.

## Beijing Event Combat Rule

- The nine-ring state can fight at an extremely high level but has limitations.
- The purpose of later soul transactions is connected to temporarily releasing higher limits.

## Writing Restrictions

- Do not let 77 solve every conflict instantly.
- Every power release must have cost, consequence, or limitation.
- Original characters must retain their own decisive moments.
