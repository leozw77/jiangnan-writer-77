# 提案、确认与撤销账本

## 规则

- 模型写出的新剧情先标 `proposed`。
- 用户明确选择、补写、继续推进，或没有否定而进入下一步时，按默认规则转为 `confirmed`。
- 用户说“不不不”、给出替代版本或指出事实错误时，旧条目转 `revoked`；所有依赖旧条目的后续事实一起检查。
- Skill/导出/记忆讨论从不触发剧情确认。
