# 质量量表

## 核心门槛

以下任一项失败，先修订再交付：

1. **人物选择**：核心转折来自人物的能力、判断和选择，而非作者强推。
2. **承诺兑现**：开头提出的主要问题在结尾得到回答或明确转化。
3. **状态变化**：主要场景前后，任务、关系、信息或代价至少改变一项。
4. **连续性**：视角、时间、伤势、秘密知情者和世界规则不自相矛盾。
5. **游戏可接管性**：玩家角色的关键行动留给玩家，NPC 不替玩家做决定。

## 十项评分

每项 0-2 分，总分 20 分。15 分以上可交付；任一核心门槛为 0 分时仍须修订。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 模式匹配 | 语域混乱 | 大体一致 | 题材机制和语言互相支持 |
| 生活系统 | 空泛背景 | 有细节 | 任务、流程或资源参与冲突 |
| 人物能力 | 只靠设定/被救 | 有能力但无作用 | 能力改变策略并有限制 |
| 人物主体性 | 被剧情推动 | 有选择 | 选择改变局面并支付代价 |
| 关系张力 | 口头说明 | 有冲突 | 债务、回避和行动互相牵引 |
| 制度/异常规则 | 只靠解释 | 基本可懂 | 通过职责、限制和后果显形 |
| 场景节奏 | 平铺或持续高音 | 有变化 | 压力、呼吸和转折服务人物 |
| 对话与声音 | 人物同声 | 有差异 | 信息、权力和潜台词同时流动 |
| 语言与意象 | 套话堆积 | 偶有准确表达 | 清晰、克制、节拍随内容变化 |
| 结尾余波 | 戛然而止/说教 | 事件结束 | 承诺兑现且后果具体 |

## 反机械化检查

- 是否刻意提高“忽然、仿佛、似乎、不知道、轻轻、缓缓、沉默”等词的密度？
- 是否机械执行“长句铺垫 + 短句落锤”？
- 是否重复雨、黄昏、天台、车站、旧票、糖、风衣、王座和宿命？
- 是否所有主角都自卑孤独，所有高潮都靠牺牲或死亡？
- 是否把强大或美丽的女性写成奖品、救赎或祭品？
- 是否用开放结尾掩盖故事没有完成？
- 是否堆品牌、古雅词、术语或势力名来冒充题材质感？

任何两项为“是”，至少重写一轮。

## 修订顺序

1. 事实与连续性
2. 题材模式与核心承诺
3. 人物能力、动机与选择
4. 场景状态变化和压力链
5. 对话潜台词与人物声音
6. 意象、抒情和句子精简

不要先打磨漂亮句子，再发现故事本身不成立。
