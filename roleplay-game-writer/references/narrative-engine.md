# 叙事引擎

先确定题材模式和故事卡，再选择 2-4 个引擎。引擎用于解决本次叙事问题，不是辨识度清单。

## 1. 日常秩序遭遇异常

**机制**：先建立家庭、校园、岗位、门派或部族的正常运转，再让异常改变其中一件小事。

**操作**：

1. 给人物一个可完成的日常任务。
2. 让异常先改变流程、资源、称呼或关系，而非立刻毁灭世界。
3. 允许人物用旧经验误解新规则。
4. 用后果纠正误解，并迫使人物选择。

**失效**：日常只做开场装饰；异常出现后社会逻辑全部消失。

## 2. 能力对抗羞耻

**机制**：人物在社会位置上弱势，却在某个具体领域有能力；压力迫使他公开使用这项能力，也暴露他最怕被看见的部分。

**操作**：

1. 先在小事中证明能力。
2. 给能力设置范围、代价或协作需求。
3. 让人物因为羞耻、身份或关系而犹豫是否使用。
4. 让能力改变局面，但不能自动解决核心关系。

**失效**：前期无证据，高潮突然天才；能力只是血统或外挂。

## 3. 关系债务产生勇气

**机制**：人物不是因“天选”勇敢，而是不愿背叛一段关系中的承诺、亏欠或共同价值。

**操作**：

1. 建立一项未完成事项：没还的帮助、没接的电话、没说的道歉、没兑现的约定。
2. 让双方对这项债务理解不同。
3. 把高潮选择设计成保护关系价值，而非只保护肉体。
4. 保留害怕、笨拙和迟疑。

**失效**：配角只是奖励；人物毫无前置证据地突然热血。

## 4. 制度压力进入现场

**机制**：用职责、流程、资源、名分和惩罚把学校、军队、王朝、公司或门派写成行动力量。

**操作**：

1. 指明人物在制度中的角色和权限。
2. 让规定同时保护某些人、伤害另一些人。
3. 让人物通过执行、绕开或违抗规则做出选择。
4. 让制度后果持续到下一场，而非击败一个坏人就消失。

**失效**：制度只由反派演讲解释；世界规则随主角需要改变。

## 5. 压力与呼吸孔

**机制**：连续增加不同性质的压力，并在其间安排普通互动，让人物改变策略并暴露关系。

**压力类型**：时间、身体、制度、秘密、信任、资源、家庭、身份。

**操作**：

1. 中短篇使用两层压力，长篇使用三层以上。
2. 每层压力必须迫使策略变化，不能只调大危险数字。
3. 呼吸孔用吃饭、维修、照料、争论小事或完成手续暴露关系。
4. 高潮同时回收至少两层压力。

**失效**：呼吸孔是无功能闲聊；升级只换更大的敌人。

## 6. 喜剧细节转为痛感

**机制**：让同一称呼、习惯、物件或笑话先建立亲密与体面，后在压力中改变含义。

**操作**：

1. 笑点必须来自人物关系和处境。
2. 重复时改变说话者、语境或结果。
3. 转痛后减少解释，让读者自己连接前后。
4. 允许结尾恢复一点日常，但不能取消代价。

**失效**：网络段子可被任意人物互换；悲剧后立刻用笑话清零。

## 7. 物件与时间回声

**机制**：普通物件、歌曲、消息、地点或动作跨越时间重复，因人物变化获得新用途和理解。

**操作**：

1. 初次出现只承担现实用途。
2. 第二次因关系或处境改变而变义。
3. 最后一次伴随动作、缺席、转交或拒绝，不解释象征。
4. 只回收真正影响人物选择的元素。

**失效**：每次出现都由作者讲解；所有生活细节都被改造成伏笔。

## 8. 彼岸映照此岸

**机制**：幻想、历史或科幻规则放大现实中的家庭、阶层、教育、战争、组织、记忆或技术伦理压力。

**操作**：

1. 先写清现实矛盾。
2. 设计同构压力，不做现实新闻的一一换名。
3. 让规则通过利益、职责、误解和代价显形。
4. 结尾回到人物生活和关系的变化。

**失效**：主题压过人物；角色替作者发表论文。

## 9. 代价之后继续生活

**机制**：保留选择的重量，也保留人继续工作的理由。光来自行动，不来自廉价反转。

**操作**：

1. 代价与人物欲望直接相关。
2. 在身体、关系、机会、身份或习惯上留下痕迹。
3. 让幸存者承担新的工作、承诺或理解。
4. 圆满结局也要有成长成本，但不强制失去生命和爱情。

**失效**：为感动而杀人；牺牲后无成本复活；最后一句强行升华。

## 组合建议

| 任务 | 推荐组合 |
|---|---|
| 校园人物片段 | 能力对抗羞耻 + 喜剧细节转为痛感 |
| 青春都市幻想 | 日常秩序遭遇异常 + 能力对抗羞耻 + 关系债务产生勇气 |
| 历史幻想 | 制度压力进入现场 + 压力与呼吸孔 + 彼岸映照此岸 |
| 武侠关系戏 | 关系债务产生勇气 + 喜剧细节转为痛感 + 物件与时间回声 |
| 城市战争 | 制度压力进入现场 + 能力对抗羞耻 + 代价之后继续生活 |
| 告别 | 关系债务产生勇气 + 物件与时间回声 + 代价之后继续生活 |
| 长篇结局 | 压力与呼吸孔 + 物件与时间回声 + 代价之后继续生活 |

## 调节器

按用户需求调整，不把默认值当铁律：

- 幻想浓度：现实 / 微幻想 / 高幻想
- 历史与制度密度：低 / 中 / 高
- 幽默功能：无 / 防御式 / 活跃
- 抒情：低 / 中 / 高
- 黑暗度：低 / 中 / 高
- 结尾：闭合 / 余韵 / 开放未来
- 节奏：生活流 / 均衡 / 高压推进
