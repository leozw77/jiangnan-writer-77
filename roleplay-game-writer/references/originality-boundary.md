# 原创化与版权边界

## 精确模仿请求

当用户要求“完全照江南写”“一模一样”“骗过读者”时，不执行声线克隆。用一句话说明将保留高层特征并写成原创版本，然后继续完成任务。

可保留的高层特征：

- 青春困境、孤独、勇气、告别和责任
- 普通生活与宏大幻想的尺度反差
- 关系推动选择
- 克制抒情、电影感场景、动作承载情绪
- 幻想映照现实
- 胜利或成长留下后果

不得保留：

- 标志性句式和可识别段落节奏的逐句仿制
- 既有角色、组织、学院、种族、力量系统、地点、神器与专属术语
- 知名人物关系几何、招募起点、关键死亡、救援结构和代表性战役
- 以作者第一人称声称私人经历或现实立场

## 同人或续写转换

1. 把用户大纲拆成中性功能：冲突、关系转折、秘密、选择、代价。
2. 删除所有作品专有名词。
3. 重建主角社会身份、核心伤口、能力来源和最终选择。
4. 改变关系几何，不能只做一对一改名。
5. 重建世界规则、派系来源和代价机制。
6. 让新结局解决新作品的承诺，而不是替原作填坑。

## 转换检查

- 不提原作名也能独立概括新故事。
- 主角的欲望、伤口与选择不同于来源作品。
- 至少两个重要关系的结构发生改变。
- 超自然规则具有新的触发条件、限制与代价。
- 输出中无受保护名词和标志性句式残留。

## 用户提供短文本

可以分析、概括和润色用户提供的文本，但不要扩展复制其中疑似来自已出版作品的长段表达。若文本明显属于原作，只做高层分析或转换为原创表达。

## 使用本地全集时

- 只提取统计、结构、题材差异和高层机制，不建立原句库、金句库或可检索段落模板。
- 不把全集中的人物关系、场景顺序和意象组合一对一迁移到新文本。
- 分析时可以指出某类作品常见的做法，但生成时必须改换社会身份、关系几何、规则来源、关键选择和结局后果。
- 不把语料高频词当作风格配方；高频副词和抽象词应主动降权。
