# 题材模式路由

先选一种主模式。只有当用户需求确实跨题材时，才叠加一种副模式。

## 1. 校园群像

**核心**：普通人的青春不是靠大事件成立，而是靠宿舍、食堂、课堂、社团、家属院和毕业去向组成的生活系统。

**场景单位**：一件小任务或小麻烦 + 人物性格碰撞 + 关系轻微位移。

**人物**：用习惯、消费选择、口头逻辑、专业能力和尴尬方式区分人物。群像人物要在主角不在场时仍有生活。

**节奏**：喜剧和琐事可以占较大篇幅；真正的情感转折晚一点出现，出现后不要长篇解释。

**避免**：把所有校园人物写成孤独天才；每段日常都暗示命运；用怀旧旁白替代当下场景。

## 2. 都市幻想

**核心**：先让人物在现代社会中的处境可信，再让异常世界重新解释他的弱点、欲望或被忽视的能力。

**场景单位**：社会性尴尬或现实任务 + 异常侵入 + 新规则带来的选择。

**人物**：主角可以自卑和迟钝，但必须在网络、游戏、专业、观察、记忆或忠诚上有真实能力。

**语言**：允许口语、流行文化和消费细节，但只选能建立时代、阶层或人物判断的细节；避免品牌清单。

**避免**：照搬“废柴被神秘学院选中”；用血统替代成长；把强大女性只写成主角的奖品或救赎。

## 3. 历史史诗

**核心**：把人物放进无法独自控制的历史、家族、战争和制度中，同时保留他的局部选择。

**场景单位**：私人关系或仪式 + 政治/军事压力 + 职责冲突。

**世界构建**：用服饰、饮食、兵器、地理、军制、继承和礼法影响行动。战略说明要同时暴露说话者的立场和关系。

**动作**：强调空间、队形、资源、判断和连锁后果。大场面必须有一个具体观察点，但不必每次都做宏大与微小的刻意对照。

**避免**：百科开场；所有统帅都说同一种宏大台词；为了史诗感不断加人名、地名和势力。

## 4. 关系武侠

**核心**：武功决定一个人能做什么，关系与性格决定他最终会不会做。

**场景单位**：礼数、饮食、交易或同行中的试探 + 一次出手或不出手 + 关系后果。

**人物**：允许善恶混杂、怯懦、眷恋和自我保护。反派也要有可理解的现实逻辑，英雄也受名分、债务和处境限制。

**动作**：招式少而清楚，动作服务判断、身份和代价。真正重要的转折常是迟到的开口、未出的刀或没有杀的人。

**避免**：无敌人物脱离社会关系；用古雅词堆出假古风；把纠缠爱情简化为纯洁/背叛二选一。

## 5. 都市科幻与战争

**核心**：用可理解的岗位、流程、设备和城市地标承载世界级危机，让英雄主义首先表现为把工作做完。

**场景单位**：技术任务 + 倒计时或资源限制 + 同伴关系 + 失误后的补救。

**视角**：适合有限视角或第一人称。人物不必理解全局，只需准确理解自己的职责和身边的人。

**情感**：把宏大损失落到轮班、食物、旧消息、工作证、储物柜、交通路线等日常痕迹上。

**避免**：用术语冒充技术；所有技术人员都像军事指挥官；爱情线与工作线互不影响。

## 6. 回望散文、序跋与后记

**核心**：从一个作品、物件、城市、歌曲或具体时刻出发，沿记忆和判断展开，最后回到时间改变了什么。

**结构**：具体触发物 -> 相关往事 -> 自我调侃或校正 -> 抽象判断 -> 新的具体画面。

**句法**：允许更长的句子、括号、插叙和联想；关键判断仍要清楚。小说模式中的高对话密度和动作推进不适用于此模式。

**语气**：坦诚但不自我神化。可以承认幼稚、误判、怯懦和偶然，不冒充作者本人的私人经历。

**避免**：每一段都升华；用名人、书影音名称堆砌文化资本；把真实人物写成只服务主题的符号。

## 混合规则

- 校园群像 + 都市幻想：保留课程、家庭和同龄人压力，让异常先改变小事。
- 历史史诗 + 关系武侠：战争负责扩大后果，武侠关系负责决定选择。
- 都市科幻 + 回望散文：正文保持岗位视角，结尾可用物件或消息形成时间回声。
- 任何模式 + 温暖结局：保留成长成本，不强制死亡、离别或爱情失败。
