# 场景与表达工艺

## 场景状态

每场戏先写清四件事：

1. 人物进场时要完成什么具体任务。
2. 谁掌握更多信息、资源或解释权。
3. 哪段关系让任务变难。
4. 离场时任务、关系、信息或代价改变了什么。

没有状态变化的场景应压缩、合并或删除。呼吸场景也要完成照料、试探、恢复、误解或承诺中的至少一项。

## 开场选择

根据模式选择，不强制动作开场：

- **关系开场**：从照料、争执、交易、等待或未完成的承诺进入。
- **任务开场**：人物正在报到、值班、赶路、维修、做饭、考试或执行命令。
- **环境异常开场**：先写可测量、可感知的异常，再写人物如何理解。
- **判断开场**：适合散文和带强叙述者的作品，用一个具体判断引出经历。
- **对话开场**：第一句话必须暴露关系或问题，不能只靠故弄玄虚。

避免先解释主题，也避免每篇都从天气、醒来、回忆或神秘来信开始。

## 信息释放

用以下载体承载设定：

1. 带立场的对话：双方因职责或利益争夺解释权。
2. 操作过程：规则通过考试、维修、礼仪、战术、交易和失败显形。
3. 物件与记录：信件、表格、装备、名单、地图和账本同时承担现实功能。
4. 人物误解：先让人物用旧经验理解新规则，再用后果纠正。

连续说明超过约 180 字时，检查能否加入决策、反问、操作或冲突。历史史诗和散文可以更长，但说明仍需改变人物理解。

## 对话

- 给每个主要人物配置四项：句长、称呼习惯、回避方式、攻击/亲近方式。
- 让人物先回答较安全的问题，再泄露真正关心的部分。
- 让玩笑改变关系位置：抢回尊严、掩盖恐惧、试探底线、推迟告别。
- 在战略或技术对话中，让信息与权力同时流动；不要把角色写成说明书。
- 情绪高潮允许一句直接的话，但这句话必须被前文行动证明。

## 人物能力

给主角一种能在场景中被验证的能力，不必是战斗力：

- 记忆、观察、计算、维修、谈判、照料、组织、说服、驾驶、写作、游戏判断或熟悉某个地方。
- 先在小事上展示能力，再让它参与重大选择。
- 能力不能无成本解决一切；压力应迫使人物改变用法或与他人协作。

## 动作与战斗

按因果链写：目标 -> 位置 -> 判断 -> 动作 -> 反作用 -> 新局面。

- 每个动作段落保留一个主要观察点。
- 写清速度和力量造成的具体限制，不连续堆“快、强、可怕”。
- 让装备、地形、队形和伤势持续影响后续动作。
- 高潮至少同时回收一条关系压力或价值冲突，否则只是规模升级。

## 喜剧转痛感

喜剧不是装饰。常用转换方式：

1. 人物用玩笑维护体面，现实后果让玩笑失效。
2. 琐碎争论建立亲密，危险来临时同一细节变成牵挂。
3. 自嘲掩盖欲望，另一人物准确说破其中一部分。

不要在悲剧后立刻用段子取消重量，也不要把每个严肃场景都安排插科打诨。

## 抒情与意象

- 情绪先落在动作、身体、物件、空间或未完成的话上。
- 同一物件再次出现时，让人物用法、所有权或缺席发生变化。
- 长句适合记忆、环境、制度和因果堆叠；短句适合决定、失误、羞耻和结果。
- 直接写“难过、害怕、后悔”并非禁忌，但不能替代证据。
- 不从原作借标志性意象组合；优先使用用户题材自然产生的物件。

## 结尾选择

- **动作收束**：人物完成或拒绝一个小动作，显示选择已经生效。
- **关系收束**：称呼、距离、分工或承诺发生可见变化。
- **物件收束**：物件恢复日常用途或获得新用途，不解释象征。
- **信息收束**：答案改变人物理解，但不再追加新谜团。
- **环境收束**：环境变化必须与人物后果有关，不能只拍空镜。

结尾应回答本篇核心问题。开放的是人物未来，不是作者欠下的情节。
