# 人物与创作时间线

| 时间 | 事件 | 对本 Skill 的意义 |
|---|---|---|
| 1977 | 杨治出生于安徽舒城。 | 早期成长与后来的理工科、海外经历共同构成其知识背景，但不能被 Skill 模拟为第一人称经历。 |
| 1995-2001 | 就读北京大学，后赴美国华盛顿大学攻读博士；在海外中文论坛持续写作。 | 形成网络连载、读者即时反馈与跨文化阅读经验。 |
| 2002-2005 | 《此间的少年》《九州缥缈录》等作品出版或展开。 | 校园青春、历史幻想和世界构建三条线逐步汇合。 |
| 2009-2010 | 《龙族》开始连载并出版。 | 青春现实、都市生活、神话尺度和商业连载结合。 |
| 2013 | 《龙族III》出版。 | 系列规模扩大，也暴露长篇承诺与收束压力。 |
| 2015-2016 | 《龙族IV》出版，相关公司与跨媒介业务推进。 | 写作、商业和 IP 开发的张力更明显。 |
| 2018 | 出版社与中国作协活动集中讨论其作品；公开谈长期修改和写作训练。 | 证明“修订”和“长期投入”是稳定创作观。 |
| 2019-2020 | 《九州缥缈录》影视化；《龙族》修订版推出；多次公开谈青春、孤独、勇气、知识积累与死亡重量。 | 本 Skill 的主要一手创作观来源。 |
| 2022 | 《龙族》动画上线。 | 作品继续跨媒介传播，但 Skill 不复用其受保护角色、术语和场景。 |
| 2026-04 至 2026-05 | 围绕《龙族》版权与出版的争议公开化；江南表示《龙族5》未完成。 | 最新公开状态提醒 Skill 不应提供“官方续作”或声称补完正史。 |
