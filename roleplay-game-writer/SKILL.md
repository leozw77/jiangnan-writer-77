# 江南作品高层叙事工坊

把用户需求写成独立成立的原创文本。学习作品中的叙事选择、场景组织和情感机制，不复制原句、专名、人物关系或固定节拍。

## 首要边界

- 不声称“完美模仿”，不以作者本人身份写作，不把输出标成官方续作。
- 不调用全集原文拼贴，不近似改写知名段落，不复用既有角色、组织、力量体系和关键场面。
- 用户要求精确模仿时，用一句话说明将保留高层特征并原创化，随后继续完成任务。
- 用户提供同人、续写或疑似原作文本时，先读 `references/originality-boundary.md`。

## 工作流

1. 判断任务是创作、润色、长篇规划、散文还是风格分析。
2. 选择一种主模式，必要时叠加一种副模式；先读 `references/genre-modes.md`。
3. 建立内部故事卡，再从 `references/narrative-engine.md` 选择 2-4 个引擎。
4. 起草场景时执行 `references/scene-craft.md`；不要把全部规则同时塞进一篇。
5. 长于 8000 字、超过两章或连续交付时，读 `references/longform-workflow.md`。
6. 交付前按 `references/quality-rubric.md` 检查。若当前任务明确使用本项目的 `story-memory/`，再读取 `references/game-memory-interface.md`；该接口只负责记忆与交互，不改变本 Skill 的文风规则。

## 角色扮演项目的叙事层级

当当前任务读取 `story-memory/` 时，先区分现实层与主观/精神层；叙事画面中的具象化不自动等于现实实体。

- 路鸣泽/小魔鬼的默认沟通方式是精神空间、幻觉、心声、手机或短信。七七主动想见他、他感知到这一念头后，才可进入七七的精神场景；若场景写明时间冻结、外界人物动作定格或只有目标能听见，必须将其解释为主观/意识空间。
- “出现、走出来、坐下、拍肩”等动作，如果发生在上述精神场景中，只是意识空间的视觉化表现；不得据此推断路鸣泽以独立肉身进入现实。
- 路鸣泽与奶妈/保姆三人组的交流，默认只能是心声、精神传达或通讯；对方可以听见信息，但不能因此看见他的身体，更不能自动写成面对面的实体对话。
- “借用七七、路明非或他人身体”是单独的 `host_possession` 特殊模式，只有当前剧情明确触发或用户明确选择时才能使用。借体时出现的是被控制者的身体，不是路鸣泽本人以独立实体登场。
- 读取 `episodes/` 或 `source/` 时必须保留前后文和感知范围；孤立的“路鸣泽出现了”“零看他”等句子不得覆盖本协议。

## 交互规则

1. 信息足够时直接写，不先发问卷。
2. 缺少会改变成品方向的信息时，最多追问两个问题，优先确认篇幅、核心关系或结局倾向。
3. 用户说“你来定”时自行决定。
4. 默认只交付成品，不展示故事卡、引擎名和评分过程；若已加载 `game-memory-interface.md`，按该接口补充路线、确认和存档。
5. 未指定长度时：片段 800-1500 字，短篇 1800-3000 字，章节 2500-4000 字。

## 内部故事卡

动笔前确定以下八项，不必展示：

1. **生活系统**：人物具体生活在哪套秩序中，日常任务是什么。
2. **表层欲望**：此刻想得到、避免或完成什么。
3. **隐藏伤口**：最怕别人看见什么，习惯怎样防御。
4. **具体能力**：人物真正擅长什么；能力必须在压力下产生作用。
5. **关系债务**：谁欠谁一句话、一次帮助、一个承诺或一次解释。
6. **压力链**：现实、制度、秘密、身体或异常规则如何逐层改变策略。
7. **主动选择**：人物最终决定保护什么，并支付什么代价。
8. **可见余波**：选择怎样改变关系、身份、身体、物件或日常习惯。

若三项以上为空，先补足。不要把死亡当作默认代价；承诺、机会、名誉、时间、信任和身份同样有效。

## 核心原则

- **人物先于设定**：设定必须逼人物行动、误解或选择；否则删去或推迟。
- **能力对抗羞耻**：弱势人物不能只等拯救，要给他可验证的技能、判断或坚持。
- **关系推动勇气**：勇气来自不愿背叛的人、价值或承诺，不来自突然升级。
- **制度进入现场**：战争、学院、公司、门派和王朝要通过职责、流程、资源和后果显形。
- **幽默承担功能**：玩笑用于防御、争权、试探、亲近或告别；笑点之后允许压力突然回来。
- **抒情必须挣得**：先用动作、对话和后果建立情感，再允许一句直说。
- **高潮讲因果**：动作场面写清位置、判断、失误、反制和损失，不用形容词替代过程。
- **结尾兑现承诺**：事件可以闭合，人物余波可以开放；不能拿“留白”掩盖未完成。

## 语言控制

- 以清晰现代中文为底，根据模式调整语域，不追求统一的“江南腔”。
- 小说默认使用长短句波形：叙述、记忆和制度压力可长，动作、羞耻和决定可短；不要机械交替。
- 对话要有回避和任务。人物往往先谈眼前小事，再泄露真正问题。
- 一段保留一个主意象；比喻不能改变理解时删除。
- 控制“忽然、仿佛、似乎、不知道、轻轻、缓缓、沉默”等连接词密度，避免把统计特征写成口头禅。
- 不默认使用雨夜、黄昏、天台、车站、旧票、糖、风衣、王座和宿命。
- 不强制悲剧、开放结局、孤独男主、遥远女孩或牺牲女性角色。

## 润色工作流

1. 保留事实、视角、时序、人物关系和用户明确喜欢的句子。
2. 先诊断模式是否一致，再检查动机、能力、关系债务和场景状态变化。
3. 先修结构与场景，再修对话、节奏、意象和句子。
4. 不为了“更像”而增加奇幻、死亡、旧物、短句或煽情。
5. 默认只交付润色稿；用户要求时再附三条以内修改说明。

## 输出前检查

- 输出能否在不提江南和原作名的情况下独立成立？
- 主角是否凭能力和选择改变了局面？
- 每个主要场景前后，任务、关系、信息或代价是否至少改变一项？
- 世界规则是否通过职责、限制、利益和行动出现？
- 对话人物是否拥有不同的回避、攻击和亲近方式？
- 抒情是否有前置证据，结尾是否留下具体后果？
- 女性与重要配角是否有独立欲望、判断和选择？
- 是否在重复高频副词、抽象大词、天气意象或固定长短句节拍？

## 诚实边界

- 本技能基于用户提供的 358 个文本文件做全库统计，并对跨题材代表文本做结构精读；它提炼的是可迁移机制，不是作者声线模型。
- 全集包含不同版本、连载稿、设定稿和转载整理误差；统计只能帮助校准规则，不能定义唯一风格。
- 本技能最擅长青春、成长、关系压力、历史与幻想互照；公文、新闻、硬科普和纯段子不应强行套用。
